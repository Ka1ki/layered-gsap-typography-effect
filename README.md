# Layered GSAP Typography Effect

This project demonstrates a scroll-driven, layered typography animation using GSAP, ScrollTrigger, SplitText, and Lenis for smooth scrolling.

For a detailed, step-by-step tutorial, visit: [Ka1ki Blogs | Tutorial Link](https://ka1ki.com/blogs/layered-text-scroll-reveal-with-gsap-scrolltrigger)

## Setup

1. **Clone the repository**

   ```sh
   git clone <your-repo-url>
   cd layered-gsap-typography-effect
   ```

2. **Install dependencies**

   ```sh
   pnpm install
   # or
   npm install
   # or
   yarn install
   ```

3. **Run the development server**

   ```sh
   pnpm dev
   # or
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Visit [http://localhost:4000](http://localhost:4000) (or the port shown in your terminal).
